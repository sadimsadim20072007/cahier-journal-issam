# مولّد المذكرة اليومية – المدرسة الرائدة

صفحة ويب (ملف واحد، بلا تثبيت) لتوليد **المذكرة اليومية** لدروس المدرسة الرائدة (TaRL).

## المزايا
- إدخال يدوي لمعطيات الحصة ومراحلها (المدة، الأنشطة، الأهداف، الوسائل، التقويم).
- وسم مستوى المعلومة: معطى صريح / استنتاج ديداكتيكي / اقتراح ديداكتيكي.
- استيراد ملف JSON الناتج عن أداة [tarl-jadada](../tarl-jadada) (حقل `daily_log`).
- قالبان لأسماء المراحل (اللغة العربية والرياضيات)، وهما اقتراح ديداكتيكي.
- طباعة / حفظ PDF، ونسخ المذكرة كنص.
- تُحفظ البيانات في متصفحك فقط (localStorage)، ولا تُرسل إلى أي خادم.

## الاستعمال
افتح `index.html` في المتصفح، أو فعّل **GitHub Pages** من إعدادات المستودع (Settings ← Pages ← Deploy from a branch ← `main` / root).
